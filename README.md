# Maahflix 🎬

Um dos meus primeiros projetos de desenvolvimento web, criado para praticar HTML e CSS por meio de uma página com vídeos sobre filmes e séries.
Este repositório registra o início da minha trajetória na programação e os primeiros conhecimentos que apliquei na construção de uma interface.

## Sobre o projeto
O Maahflix apresenta um vídeo em destaque relacionado a “Através do Aranhaverso” e uma galeria com cinco miniaturas que levam a vídeos no YouTube.
A página tem identidade visual própria, com fundo escuro, destaque em lilás e detalhes em azul.

## Recursos
- Vídeo do YouTube incorporado à página.
- Galeria de miniaturas com links para vídeos.
- Rolagem horizontal na galeria.
- Efeito de destaque ao passar o mouse sobre as imagens.
- Fontes personalizadas com Google Fonts.

## Tecnologias utilizadas
- HTML.
- CSS.
- Flexbox.
- Google Fonts: Oswald e Merriweather.
- Incorporação de vídeo com iframe do YouTube.

## O que pratiquei
- Organização de conteúdo com cabeçalho, seções, títulos e links.
- Estilização com cores, fontes, margens e espaçamentos.
- Posicionamento de elementos com Flexbox.
- Uso de imagens e conteúdo externo.
- Efeitos visuais com `hover` e `opacity`.
- Rolagem horizontal com `overflow-x`.

## Como executar
1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.
Não é necessário instalar dependências. É preciso ter conexão com a internet para carregar os vídeos, as miniaturas e as fontes.

## Arquivos
- `index.html`: estrutura e conteúdo da página.
- `styles.css`: estilos e organização visual.

## Sobre esta versão
O projeto utiliza apenas HTML e CSS, sem JavaScript ou backend. Os vídeos são disponibilizados pelo YouTube.
Esta versão mantém a proposta inicial como registro do meu aprendizado. Melhorias futuras podem incluir adaptação para celulares e descrições alternativas nas imagens.
